# Орбита

Учебная платформа колледжа: короткие уроки-карточки, тренажёр кода с автопроверкой, очки опыта и отчёт преподавателя.
Работает в браузере на телефоне и компьютере, без установки и без сервера — это статический сайт для GitHub Pages.

## Курсы

| Папка | Курс |
|---|---|
| `courses/web-ksk` | ДУП.05 «Основы разработки веб-приложений», специальность «Компьютерные системы и комплексы» (КСК114, КСК114д, КСК134, КСК154) |

## Как устроено

- `index.html` — точка входа. Подключает движок, курсы и уроки.
- `js/` — движок: интерфейс (`app.js`), редактор кода, запуск и автопроверка кода в изолированном окне (`runner.js`), хранение прогресса (`store.js`).
- `courses/<курс>/course.js` — структура курса по рабочей программе: темы, занятия, часы.
- `courses/<курс>/lessons/` — по одному файлу на занятие: `l-…` — теория, `pz-…` — практическое занятие. Формат шагов и заданий описан в начале `l-1-1.js` и `pz-01.js`.

Чтобы добавить занятие: положить файл в `lessons/` и подключить его строкой `<script>` в `index.html`. Номера уже выложенных занятий и заданий не меняются — иначе у студентов собьётся прогресс.

## Оценивание

Баллы за ПЗ → оценка: от 85% — «5», от 70% — «4», от 50% — «3», ниже — «не зачтено» (можно доделать).
Подсказка снижает баллы за задание на 30%, просмотр решения — до нуля.

## Облако и публикация

- `js/config.js` — адрес веб-приложения Google Apps Script. Пустой адрес — прогресс хранится только в браузере.
- `apps-script/Code.gs` — серверная часть в Google Таблице: коды студентов, прогресс, оценки, отчёт по паролю, ограничение попыток входа, замена кода.
- `node build.mjs site` — собирает сайт в папку `../site` (она и публикуется на GitHub Pages). Эталонные решения из уроков в сайт не попадают: сборка добавляет их к `Code.gs` и сохраняет как `apps-script/Orbita.gs` — этот один файл целиком вставляется в Apps Script.
- `node tools/mock-api.mjs` — тестовый сервер, который запускает `Code.gs` без Google, для проверки перед публикацией.
- `node build.mjs preview` — всё одним файлом в `dist/orbita.html` для предпросмотра.

Исходники с решениями хранятся только локально (этот репозиторий без удалённого адреса), на GitHub — только собранный сайт.
